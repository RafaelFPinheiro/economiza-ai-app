# economizai

Projeto mobile para visualização de gastos mensais.

## Feature principal — Monthly Spending Dashboard

Resumo: Implementa um painel de visão mensal de gastos que exibe um resumo das despesas, lista de transações e um breakdown por categoria. Inclui navegação entre meses e hooks para buscar dados mockados em `app/src/services/mocked/monthlySpendingService.ts`.

Arquivos relevantes:
- `app/src/features/monthly-spending/` — componentes, hooks e tela principal.
- `specs/001-monthly-spending-dashboard/` — especificações, plano e tarefas.

Como rodar (exemplo):

```bash
cd app
npm install
# se for Expo
expo start
```

Contribuições: leia `specs/001-monthly-spending-dashboard/spec.md` para entender requisitos e critérios de aceitação.
